# Week 01 — Introduction to Linux Server

**Course:** Linux Server Administration  
**Class:** Year 4, Semester 2  
**Instructor:** Pheav Seyha

## Learning Objectives

By the end of this lesson, students will be able to:

- Understand what a Linux Server is
- Identify common Linux distributions
- Understand Linux server architecture
- Use basic Linux commands
- Navigate the Linux file system
- Check system information
- Practice using Google Cloud Shell

## Topics

1. Introduction to Linux
2. Linux Server vs Desktop
3. Linux Distributions
4. Linux File System
5. Basic Linux Commands
6. System Information Commands
7. Introduction to Cloud Shell
8. Hands-on Practice
